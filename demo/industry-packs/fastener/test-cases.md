# 紧固件行业客服验收测试用例

用于资料导入、RAG 检索和客服回答验收。

## 1. 标准与规格识别

| 用户问题 | 预期关注点 |
| --- | --- |
| DIN 933 六角螺栓和 GB 5783 有什么区别？ | 标准体系、外六角螺栓、尺寸定义 |
| M8x30 的六角螺栓你们有常规规格吗？ | 规格、是否常规件、配套产品 |
| 我要外六角螺栓，但是没写标准，怎么确认？ | 引导补齐标准、规格、材质、等级 |
| DIN 912 属于什么类型的紧固件？ | 内六角圆柱头螺钉 |

## 2. 材质判断

| 用户问题 | 预期关注点 |
| --- | --- |
| 304 和 316 不锈钢哪个更耐腐蚀？ | 使用环境、耐腐蚀差异 |
| 海边项目建议用 304 还是 316？ | 高盐雾环境优先确认 316 |
| 普通室内设备装配一定要用 316 吗？ | 304 通常可满足、避免过度推荐 |
| 碳钢和不锈钢的成本差异会很大吗？ | 材质差异、成本提醒、需结合规格数量 |

## 3. 强度等级

| 用户问题 | 预期关注点 |
| --- | --- |
| 8.8级和10.9级螺栓怎么选？ | 载荷、工况、图纸要求 |
| 12.9级是不是一定比 10.9级更适合？ | 不可简单替代、需结合工况 |
| 高强度螺钉可以直接改成电镀件吗？ | 工艺风险、氢脆提醒 |
| 模具上用的内六角一般选什么等级？ | 12.9级常见，但仍需确认图纸 |

## 4. 表面处理

| 用户问题 | 预期关注点 |
| --- | --- |
| 镀锌和达克罗的区别是什么？ | 防腐等级、应用场景 |
| 户外支架用发黑处理可以吗？ | 不建议，需考虑更强防腐 |
| 热镀锌一般适合什么项目？ | 户外、结构件、电力类 |
| 客户只说要防锈，这种怎么回复？ | 追问环境、防腐要求、盐雾等级 |

## 5. 产品与配套

| 用户问题 | 预期关注点 |
| --- | --- |
| DIN 933 M8x30 六角螺栓多少钱？ | 命中产品报价与参数 |
| 你们有和 M8 外六角配套的螺母和平垫吗？ | DIN 934 六角螺母、ISO 7089 平垫 |
| 牙条可以按 1 米和 2 米切段供货吗？ | DIN 975、供货方式 |
| M8 不锈钢配什么垫圈比较常见？ | 平垫、规格匹配 |

## 6. 交期与包装

| 用户问题 | 预期关注点 |
| --- | --- |
| 常规 DIN 933 螺栓交期一般多久？ | 现货/排产、需结合数量 |
| 可以做小盒装再出外箱吗？ | 包装方式、物流影响 |
| 出口项目包装能按托盘方式走吗？ | 包装确认、出货要求 |
| 客户要急单，客服能不能直接承诺三天出货？ | 不能直接承诺、需内部确认 |

## 7. 非标与定制

| 用户问题 | 预期关注点 |
| --- | --- |
| 非标件可以按图纸做吗？ | 先收图纸、材质、数量 |
| 没有图纸只有样品，能报价吗？ | 样品评估、补齐关键信息 |
| 非标紧固件的 MOQ 一般怎么确认？ | 结合工艺、模具、数量 |
| 可以做指定 logo 或特殊头型吗？ | 定制可行性、需技术确认 |

## 8. 客服能力边界

| 用户问题 | 预期关注点 |
| --- | --- |
| 这个非标件你现在就给我报个准确价格 | 不直接承诺，先收资料 |
| 这个螺栓一定能通过某认证吗？ | 不编造认证，需确认文件 |
| 你们库存有多少？ | 没有资料时不能虚构库存 |
| 这个规格一定能下周交货吗？ | 没有确认前不能承诺交期 |
